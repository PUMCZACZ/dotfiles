## Proposed target

In WezTerm's `open-uri` event, accept local file paths only (including `file://` URI via `wezterm.url.parse`); resolve relative paths against the source Herdr pane's `cwd` after identifying it unambiguously from terminal identity and click location. Use Rider for `.cs`, `.fs`, `.vb`, or when an ancestor has `*.sln`, `*.slnx`, or `*.csproj`; use PhpStorm otherwise. Ignore unsupported URI schemes and absent/invalid local targets safely, preserving normal external URL handling.
